# @rahrow/ui

Small React UI primitive set and global styles for RahRow interface packages.

This package owns the Tailwind global stylesheet, design tokens, `cn`, and the
small primitive controls shared by desktop and mobile: buttons, cards, form
fields, basic inputs, status badges, alerts, tabs, separators, skeletons, and a
spinner.

Composed product widgets, app-specific state, feature screens, protocol
behavior, and platform behavior stay in the owning app or shared domain package
until a stable cross-interface contract exists.
