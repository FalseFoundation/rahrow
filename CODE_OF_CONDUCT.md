# Code of Conduct

RahRow is built through direct, respectful technical collaboration.

## Expected Behavior

- Discuss ideas and code without attacking people.
- Give specific, actionable feedback and explain important tradeoffs.
- Welcome contributors with different experience levels and backgrounds.
- Credit work accurately.
- Respect privacy, boundaries, and requests to stop an interaction.
- Prioritize project safety when handling repositories, credentials, or
  security-sensitive reports.

## Unacceptable Behavior

- Harassment, threats, discrimination, or sexualized conduct
- Personal insults, intimidation, or repeated hostile disruption
- Publishing private information without permission
- Deliberately damaging project infrastructure or contributor work
- Retaliation against someone who reports a concern in good faith

## Enforcement

Project maintainers may edit or remove contributions, comments, or participation
that violate these expectations. Responses may range from a private warning to
a permanent ban, based on severity and repeated behavior.

Report conduct concerns privately to the project maintainers through the
repository owner's private contact channel. Do not open a public issue when a
report contains private or safety-sensitive information.

Maintainers handling a report should protect confidentiality, avoid conflicts
of interest, gather relevant context, and communicate the resulting action to
the reporting person when appropriate.

This code applies in project spaces and when someone is representing RahRow in
public.
