# RahRow

RahRow is an open-source, cross-platform, privacy-first V2Ray client platform.
This repository hosts the shared monorepo foundation for apps, packages, runtime
adapters, and integration tooling.

## Core Promise

- Cross-platform clients share one consistent domain model and protocol layer.
- Runtime adapters remain modular so protocols can evolve independently.
- Privacy-first defaults are designed into architecture decisions.
- Desktop, mobile, web, and server surfaces can move in parallel.
- The monorepo keeps tooling, docs, and product boundaries explicit.

## Current Status

RahRow is currently in scaffold and architecture-buildout mode. Core V2Ray
runtime behavior, transport orchestration, profile UX, and production network
features are not finalized yet.
